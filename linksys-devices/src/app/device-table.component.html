Username Password

The app sends JNAP requests through the configured application proxy route. The router IP is defined by the server routing rules, so no router IP entry is required in the browser form. You can also provide credentials in the URL using `u` and `p` query parameters, where the password is URL-safe encoded for sharing. When the credentials are present in the URL, the list loads automatically and the credential inputs are hidden.
